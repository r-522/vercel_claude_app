# 06_総合テスト仕様書

## 1. 総合テスト仕様書の概要

**作成日**: 2026-06-18  
**対象版**: 1.0  
**対象要件定義書**: 01_要件定義書.md  

本ドキュメントは、システム全体の機能要件・非機能要件・セキュリティ要件を検証するための総合テスト仕様を定義します。

---

## 2. テスト方針

### 2.1 テスト目的

- システム全体が要件定義書を満たすことを確認
- ユーザーシナリオが正常に動作することを検証
- パフォーマンス・セキュリティ基準を達成
- リリース可否の判断基準とする

### 2.2 テストレベル

| レベル | 略称 | 内容 |
|-------|------|------|
| ユーザー受け入れテスト | UAT | ビジネス要件・ユーザーシナリオ |
| システムテスト | ST | 全機能・エンドツーエンド |
| パフォーマンステスト | PT | 性能指標の計測 |
| セキュリティテスト | SecT | セキュリティ対策の検証 |

### 2.3 テスト環境

- **環境**: Vercel Staging（Preview デプロイ）
- **ブラウザ**: Chrome, Firefox, Safari, Edge
- **OS**: Windows 11, macOS

> **注意**: パフォーマンス実測値（FCP/LCP/CLS 等）は実際に計測後に記入してください。本書の「実測値」欄はすべて空欄です。

### 5.3 CSRF 対策確認

#### SecT-CSRF-001: SameSite=Lax の効果

| 検査項目 | 詳細 |
|---------|------|
| `SameSite=Lax` 設定 | クロスサイトの POST リクエストにクッキーは送付されない |
| 制限事項 | `Strict` ではなく `Lax` のため、トップレベルナビゲーション（GET）では送付される |

> **注意**: 完全な CSRF 防止には `SameSite=Strict` または CSRF トークンが必要。現状は `Lax` での軽減措置。
